# Luxthos UI

Luxthos UI is a World of Warcraft interface installer and profile manager for the Luxthos community.

## Purpose

- Make installing the recommended Luxthos World of Warcraft interface easier and more reproducible.
- Install a curated list of third-party addons from their official distribution sources.
- Apply Luxthos profiles and interface configuration.
- Support backup, repair and update workflows.
- Initial game support is World of Warcraft Retail, with additional WoW flavours planned.

## Distribution rules

- Luxthos UI does not claim ownership of third-party addons.
- Addons remain owned and maintained by their respective authors.
- CurseForge-hosted addons will only be downloaded through CurseForge when the addon author permits third-party distribution.
- If third-party distribution is disabled, Luxthos UI will direct the user to the official CurseForge page for manual installation.
- Addons will not be modified or rehosted by Luxthos UI.
- The application will verify downloaded files before installation.

## Free and manual availability

Luxthos addon recommendations, Luxthos profiles and manual installation instructions remain freely available at [luxthos.com](https://www.luxthos.com/).

The desktop application is an optional convenience and automation tool for supporters.
